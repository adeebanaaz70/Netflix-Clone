# Netflix Clone 🎬

A Netflix landing page clone built using **HTML and CSS** as my first web development project.

## ✨ Features

* Netflix-style hero section
* Trending movies and shows section
* Hover effects on movie cards
* "More reasons to join" section
* Frequently Asked Questions section
* Email registration sections
* Netflix-style footer
* Horizontal scrolling movie cards

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts

## 📚 What I Learned

While building this project, I practiced:

* HTML page structure
* CSS Flexbox
* CSS Grid
* Positioning and z-index
* Background images and overlays
* Gradients
* Hover effects
* Typography
* Basic layout and styling

## 🚀 About the Project

This project was created while learning the fundamentals of web development. I built most of the project using the HTML and CSS concepts I had learned at the time and used it to practice creating a complete website layout from scratch.

This is my **first web development project** and an important part of my journey into frontend development.
